# ChimeraEngine

A modular open-source game engine designed for experimentation,
custom rendering pipelines, gameplay systems and engine architecture research.

## Attribution

If you use ChimeraEngine in:

- games
- public projects
- forks
- modified engine versions
- derived tools or frameworks

you must include:

- the original engine name: ChimeraEngine
- a link to the original repository

Attribution may appear in:

- credits
- documentation
- repository README
- about page

---

## Forks and Derivative Versions

Forks and custom versions are allowed.

However, derivative projects must not present themselves
as the official ChimeraEngine project.

Please clearly indicate when a project is a modified or unofficial version.
